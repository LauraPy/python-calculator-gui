# Simple Python Calculator

A functional GUI-based calculator application built with Python.

## Description
This project is a desktop calculator that performs basic arithmetic operations. It was developed using the Tkinter library to provide a clean and user-friendly graphical interface.

## Features
- Basic operations: Addition, Subtraction, Multiplication, Division.
- Clear Entry (AC) functionality.
- Intuitive and responsive graphical user interface.

## How to Run
1. Download or clone the repository.
2. Run the main file:
   python calculator.py

## Requirements
- Python 3.x
- Tkinter (standard with most Python installations)
